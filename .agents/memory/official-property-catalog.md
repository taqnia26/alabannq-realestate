---
name: Official property catalog
description: Source-of-truth rule for property content and imagery on the Alabnq site.
---

Only show property listings, prices, descriptions, and public image links that are currently published by alabannq.com. Do not supplement the catalog with fictional offers, placeholder prices, or stock-property imagery.

**Why:** The site represents a real-estate company, so invented listing information can mislead prospective customers and undermine trust.

**How to apply:** When changing the catalog, verify each entry against its official listing page, retain a link to that source, and reference the public image URL rather than copying the media asset into the project.
